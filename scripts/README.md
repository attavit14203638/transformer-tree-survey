# Figure Generation Scripts

Scripts used to generate the publication figures in the manuscript. All scripts read cleaned CSV data from `data/` and write output figures to `figures/`.

## Prerequisites

```bash
pip install -r requirements.txt
```

**Python**: 3.9+

## Usage

Run any script from the repository root or from the `scripts/` directory:

```bash
cd scripts
python timeline.py
python architecture_sankey.py
python rq1_performance_efficiency.py
python rq2_generalization.py
python rq3_training_strategies.py
```

## Script-to-Figure Mapping

| Script | Output Figure | Manuscript Reference |
|---|---|---|
| `timeline.py` | `figures/timeline.jpg` | Fig. 4 — Temporal adoption of transformer architectures |
| `architecture_sankey.py` | `figures/architecture_sankey.jpg` | Fig. 6 — Transformer architecture taxonomy Sankey diagram |
| `rq1_performance_efficiency.py` | `figures/rq1_performance.jpg` | Fig. 7 — Performance-efficiency trade-offs |
| `rq2_generalization.py` | `figures/rq2_generalization.jpg` | Fig. 8 — Cross-environment generalization |
| `rq3_training_strategies.py` | `figures/rq3_training.jpg` | Fig. 9 — Training strategy and data efficiency |
| `utils.py` | — | Shared utility: data loading and figure saving |

**Note**: `survey_summary.jpg`, `annotation_task_sensor_summary.jpg`, and `architecture_summary.jpg` were produced manually and are not generated by these scripts.

## Input Data

All scripts load cleaned CSV files from the `data/` directory via `utils.py`:

| File | Description |
|---|---|
| `papers_clean.csv` | Paper metadata (title, year, citation key, venue) |
| `models_clean.csv` | Model architectures and backbones per paper |
| `performance_clean.csv` | Reported performance metrics (normalized to 0–100 scale) |
| `geography_clean.csv` | Study site locations, biomes, and countries |
| `training_clean.csv` | Training configurations (samples, strategies, compute) |
| `datasets_clean.csv` | Dataset metadata (size, resolution, modality) |

## Output

All figures are saved as JPEG (300 DPI) to the `figures/` directory.
